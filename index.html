Process

How It Works

🎤

Voice Input

User speaks a natural language command through the microphone.

🧠

Speech Recognition

Local or browser-based engine transcribes audio to text in real time.

⚙️

Command Processing

Intent parser maps the transcript to a validated, safe command action.

💻

PC Automation

Desktop backend executes only explicitly whitelisted, confirmed actions.

✅

User Feedback

Confirmation and result are shown in the dashboard and spoken aloud.

Technical Architecture

System Design

The frontend communicates with a local desktop backend over a trusted WebSocket. The backend validates every command before execution — no arbitrary shell commands are ever run from recognized speech.

Frontend

Web Interface

HTML / CSS / JS — this page

Speech API

Browser Web Speech API (with fallback notice)

WebSocket Client

Connects to local backend on ws://localhost:8765

Backend

Command Parser

Intent classification & parameter extraction

Whitelist Engine

Only explicitly allowed actions are dispatched

Confirmation Gate

Sensitive actions require explicit user approval

OS-level interaction (platform TBD)

Response System

Text-to-speech & dashboard feedback
